# Frontend Application

A modern, responsive financial portal and alternative credit analytics platform built with React, Vite, TailwindCSS, and TanStack Router.

## Features

- **Data Consent Flow**: Multi-step interactive applicant onboarding and consent architecture.
- **Credit Score Engine & Result Dashboard**: Interactive credit breakdown, factor analysis, and scenario modeling.
- **Credit Advisor**: Multilingual assistant and actionable recommendations.
- **Officer & Administration Portal**: Dashboard for reviewing applications, underwriting signals, and portfolio metrics.
- **Responsive & Accessible**: Optimized for desktop and mobile, with light and dark theme support.
- **Internationalization**: Localized vernacular support (English, Hindi, Gujarati, Tamil).

## Tech Stack

- **UI & Layout**: React 19, TailwindCSS, Radix UI primitives, Lucide Icons
- **Routing**: TanStack Router
- **Build Tool**: Vite
- **Animations**: GSAP, Motion
- **State Management**: Zustand, TanStack Query

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the local development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

4. Preview the production build:
   ```bash
   npm run preview
   ```
