# Belgrade Arbor — Architectural & Botanical Residence Complex

A high-fidelity recreation of the award-winning official website for [Belgrade Arbor](https://belgradearbor.rs/en), a premier residential and commercial development in New Belgrade featuring tree canopy-inspired architecture, refined botanical aesthetics, and smooth editorial interactions.

## 🚀 Live Demo & Development

- **Live URL Reference**: https://belgradearbor.rs/en
- **Local Dev Server**: http://localhost:3005/

### Running Locally

```bash
cd portfolio/belgradearbor
npm install
npm run dev
```

## 🎨 Architectural Highlights

1. **Floating Frosted Botanical Navbar**:
   - Translucent rounded pill navbar (`#1F261E/80`) with backdrop blur.
   - Animated SVG hamburger to X icon state morph.
   - Golden tree canopy monogram logo.
   - Dual-layer rolling "Inquire" button with arrow animation.

2. **Canopy Hero & Editorial Display**:
   - High-contrast editorial typography inspired by Editorial Old / Newsreader.
   - Subtitle: *"A New Chapter in Prestigious Living on Bulevar heroja sa Košara"*.
   - Architectural elevation badges and GPS coordinates readout.

3. **Interactive Residence & Floorplan Inspector**:
   - Filter through Penthouses, Duplexes, and Family Apartments.
   - Dynamic square meter, room count, and sunlight orientation readouts.
   - High-fidelity SVG architectural blueprint diagrams.

4. **Awwwards Sticky Ribbon & Botanical Footer**:
   - Vertical floating Awwwards badge on the right viewport edge.
   - Expansive dark forest footer with gold monogram and contact inquiry inputs.
