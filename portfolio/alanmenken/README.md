# Alan Menken Official Website Clone

A 1:1 high-fidelity recreation of the official website of legendary EGOT composer [Alan Menken](https://www.alanmenken.com/).

## 🚀 Live Demo & Development

- **Live URL Reference**: https://www.alanmenken.com/
- **Local Dev Server**: http://localhost:3002/

### Running Locally

```bash
cd portfolio/alanmenken
npm install
npm run dev
```

## 🎨 Architectural Highlights

1. **Entrance Sequence & Synchronized Audio**:
   - Immersive dark splash screen with animated handwritten SVG signature.
   - Cinematic introductory sequence featuring Aladdin & Jasmine flying on the magic carpet.
   - User-initiated audio unlock routing synchronized orchestral playback from video elements.

2. **Featured Works Dynamic Accordion**:
   - 10-column interactive musical accordion featuring flagship Disney and Broadway works:
     - *Pocahontas*, *Little Shop of Horrors*, *Aladdin*, *The Hunchback of Notre Dame*, *Hercules*, *Beauty and the Beast*, *Enchanted*, *Newsies*, *Tangled*, *The Little Mermaid*.
   - Dynamic hover expansion with video fade-in on desktop and touch gestures on mobile.

3. **Dual View Mode Switcher**:
   - Interactive toggle switching between full interactive accordion strips and high-density multi-column editorial grid.

4. **Typography & Aesthetics**:
   - Custom inlined base64 webfonts: `Clearface ITC W01` serif display typography.
   - Soft linen warm-gray background palette (`#e7e5df`).
