# SweetTape — Stick By You

A high-fidelity recreation of the playful, tactile e-commerce landing page for [SweetTape](https://sweet-tape.com/) — celebrating 3 generations of tape manufacturing with bold pop colors, adhesive strip mechanics, and kinetic product exploration.

## 🚀 Live Demo & Development

- **Live URL Reference**: https://sweet-tape.com/
- **Local Dev Server**: http://localhost:3006/

### Running Locally

```bash
cd ecommerce/sweettape
npm install
npm run dev
```

## 🎨 Architectural Highlights

1. **Tactile Tape Strip Hero**:
   - Jaunty tilted adhesive strips with jagged serrated edges.
   - High-impact retro grotesque typography: *"STICK BY YOU — Built for everyday moments"*.
   - Dynamic hover peeling animations and tape unrolling mechanics.

2. **6-Tape Interactive Product Carousel**:
   - Explore Cloth Tape, Masking Tape, OPP Packaging Tape, Stationery Tape, Double-Sided, and Duct Tape.
   - Interactive peel & stick demo with adhesive strength ratings.

3. **Retro Pop Color Palette**:
   - High-energy Tape Yellow (`#F7D000`), Coral Flame (`#FF7B5F`), Duck-Egg Cyan (`#50CBFF`), and Olive/Kraft accents.
