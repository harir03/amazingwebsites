# Agrumea Farm — Sicilian Artisan Marmalades, Spreads & Preserves

A high-fidelity recreation of the award-winning official website for [Agrumea Farm](https://www.agrumeafarm.it/en), a premier Sicilian artisan producer celebrating volcanic soil biodiversity, sun-ripened citrus fruits, Etna pistachios, and slow Mediterranean pantry craft. Winner of Awwwards **Site of the Day** (Nov 5, 2026).

## 🚀 Live Demo & Development

- **Live Reference**: [https://www.agrumeafarm.it/en](https://www.agrumeafarm.it/en)
- **Local Dev Server**: http://localhost:3009/

### Running Locally

```bash
cd ecommerce/agrumeafarm
npm install
npm run dev
```

## 🎨 Design & Culinary Systems

1. **Sunlit Mediterranean Provenance Palette**:
   - Terracotta (`#DF5C32`), Olive Grove Green (`#364B38`), Lemon Citron (`#F5CE43`), Warm Parchment (`#F8F5EE`).
2. **Artisanal Pantry Jar Selector**:
   - Interactive switcher between Sicilian blood orange marmalade, 65% pistachio pesto, sweet almond spread, and Nocellara olive tapenade with ingredient breakdowns and pairing secrets.
3. **Typography**:
   - High-contrast editorial serif (`Instrument Serif`) combined with clean grotesque sans (`Plus Jakarta Sans`).
