# Overworld Audio — Game Audio & Sonic Architecture

A high-fidelity recreation of the official studio showcase website for [Overworld Audio](https://overworldaudio.com/), an audio co-development studio delivering immersive sound design, procedural audio, and music implementation for games and interactive experiences.

## 🚀 Live Demo & Development

- **Live URL Reference**: https://overworldaudio.com/
- **Local Dev Server**: http://localhost:3007/

### Running Locally

```bash
cd media/overworldaudio
npm install
npm run dev
```

## 🎨 Architectural Highlights

1. **Interactive Sonic Frequency Visualizer**:
   - Web Audio procedural sound generation with live oscillating canvas.
   - Interactive draggable frequency nodes shaping the harmonic spectrum.

2. **Game Audio Reel Deck**:
   - Multi-track stem audio player with live decibel peak meters, solo/mute toggles, and waveform scrubs.

3. **High-Contrast Dark Studio Palette**:
   - Deep obsidian noir (`#08080A`), studio midnight slate (`#13151F`), and electric sonic lime (`#A3E635`).
