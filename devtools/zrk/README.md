# ZIRKA Interceptor (ZRK Technology)

A high-fidelity recreation of the award-winning official website for [ZIRKA Interceptor](https://www.zrk.technology/) by Qream. Autonomous counter-UAS interceptor system with optical auto-guidance designed against Shahed-type drone threats. Winner of Awwwards **Site of the Day** (Nov 9, 2026).

## 🚀 Live Demo & Development

- **Live Reference**: [https://www.zrk.technology/](https://www.zrk.technology/)
- **Local Dev Server**: http://localhost:3010/

### Running Locally

```bash
cd devtools/zrk
npm install
npm run dev
```

## 🎨 Technical & Aerospace Highlights

1. **Military Aerospace HUD & Tactical Telemetry**:
   - Stealth dark canvas (`#0A0C0E`), radar grid overlay, warning alert amber (`#FF5500`), and targeting cyan (`#00F0FF`).
2. **Interactive Targeting Radar**:
   - Conic radar sweep with cursor-controlled targeting reticle and real-time azimuth and range calculation.
3. **Threat Specification Comparison Matrix**:
   - Direct physical capability matrix contrasting Shahed-136 threat dynamics with Zirka kinetic overmatch parameters.
4. **Autonomous Mission Architecture**:
   - 4-phase sequence from early acoustic detection to optical lock and kinetic neutralization.
